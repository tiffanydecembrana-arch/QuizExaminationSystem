Example Format: 
1. What does CPU stand for?

A. HTML
B. Windows
C. CSS
D. SQL
Answer: B

Q3. What is used to style a webpage?

B: CSS

D: Python
Answer: B

Q.4 - What is the purpose of RAM?
A - Store temporary data
B - Print documents
C - Browse websites
D - Protect the monitor

• Use A, B, C, and D to identify the four choices.
• Choices may use A), A., A:, or A -.
• Use Answer: followed by A, B, C, or D.
• You may also use Correct Answer: or Answer =.
• You may use 1, 2, 3, or 4 for the correct answer.
• You can use the complete correct choice as the answer.
• You can create up to 100 questions.
